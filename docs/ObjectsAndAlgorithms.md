# Объекты и алгоритмы

## Упорядоченная таблица на массиве

Таблица, содержащая упорядоченные по ключу элементы, при работе с ней предусматривающая следующие операции:
- Бинарный пoиск - O(logN),
- Добавление путём прохождения по массиву для поиска места, удовлетворяющего условиям, вставка полинома и сдвиг остальных - O(N +logN),
- Удаление с помощью бинарного поиска места для удаления с последующим сдвигом элементов, находящихся правее - O(N +logN).

## Пользовательский интерфейс

Содержит кнопки для сохранения в файл, открытия файла формата “.txt”. Содержит кнопку “запустить программу” для запуска программы. Содержит поле ввода кода программы с нумерацией строк.

## Иерархический список

Иерархический список представляет собой набор списков, структурированных в специальном иерархическом порядке, в котором выбор начального пункта приводит к другому списку, содержащему дополнительные элементы, которые могут вести к другому списку и т.д., пока не найдется нужный элемент. Иерархический список позволяет хранить информацию в соответствии с подчинением одних данных другим, а также будет предоставлять возможность получать к ним доступ и обрабатывать данные.

## Стек

Стек позволяет добавить в конец, удалить из конца, получить последний элемент, узнать количество хранимых элементов. Реализуется на основе динамического массива.

## Исполнение

### Разбиение на лексемы

Текст программы разбивается на лексемы (ключевые слова языка, имена переменных, строковые и числовые литералы, скобки, знаки арифметических и логических операций). В конце полученной последовательности лексем добавляется фиктивный элемент, обозначающий конец файла, если процесс разбиения прошел успешно, или обозначающий ошибку, если обнаружена ошибка.

### Разбиение на операторы

Предположим процесс разбиения находится на некоторой лексеме. По этой лексеме однозначно определяется тип оператора. Для простоты, блоки кода, блоки объявления констант и переменных будем считать операторами. 
Находим конец оператора в зависимости от его типа (например, это может быть символ ‘;’ для оператора вывода на экран).

Весь отрезок лексем, соответствующий оператору, делится на логические блоки. Например, в условном операторе выделяется условное выражение и блок исполняемого кода. Условные и логические выражения дополнительно преобразуются в постфиксную форму.

Далее процесс продолжается с лексемы, следующей за последней вершиной оператора.

На выходе алгоритма получаем контекст исполнения программы.

### Преобразования логических и арифметических операций в постфикс

На вход принимается последовательность лексем, представляющая выражение в инфиксной форме. Выполняется преобразование выражения в постфиксную форму с учетом приоритета операторов и скобок.

### Контекст исполнения

Контекст исполнения содержит указатель на иерархический список, представляющий программу, таблицы констант и переменных.

### Исполнение программы

На вход принимается контекст исполнения программы. Выполняется обход иерархического списка, и выполнение соответствующих операторам действий. Под действиями понимаются операции ввода/вывода, изменение значений переменных.

### Драйвер исполнения

Функция/статический метод, агрегирующая процесс исполнения программы. Поданный на вход текст программы проводится через описанные выше этапы. Если исполнение прошло успешно, возвращается таблица переменных, иначе возвращается ошибка.
